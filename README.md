# IMovies 🎬

IMovies is a full-stack movie ticket booking web application built using the MERN stack.

## Features
- User registration and login
- Browse and search movies
- Select theatres, showtimes, and seats
- Book and cancel tickets
- Demo payment system
- Admin dashboard for managing movies, users, and bookings

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- Bootstrap

## Installation

```bash
npm run install:all
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:5001`

## Testing

```bash
npm test
```

## Note
Payments are simulated for demonstration purposes only.
